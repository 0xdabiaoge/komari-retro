# Uninstall Komari Agent

Open the delete dialog from the node list or node details page, select the target platform, copy the generated command, and run it on the monitored host. Deleting a node in the dashboard only removes its record; it does not execute commands remotely.

The default service or container name is `komari-agent`. If installation used `--install-service-name`, enter the same name in the dialog. If it used `--install-dir`, enter the original directory too. A mismatch can leave the service running or the installation files in place.

The generated command removes the Agent executable and auto-discovery identity file, and removes the install directory only if it is empty. Other files are preserved. Docker cleanup removes the selected container and its bind-mounted auto-discovery file, while keeping images and named volumes.

## Manual uninstall

### Linux (systemd)

The default system installation uses `/opt/komari`:

```bash
service_name=komari-agent
sudo systemctl stop "$service_name.service" 2>/dev/null || true
sudo systemctl disable "$service_name.service" 2>/dev/null || true
sudo rm -f "/etc/systemd/system/$service_name.service"
sudo systemctl daemon-reload
sudo rm -f /opt/komari/agent /opt/komari/auto-discovery.json
sudo rmdir /opt/komari 2>/dev/null || true
```

An unprivileged installation uses `systemctl --user`; its default files are in `$XDG_DATA_HOME/komari` (or `$HOME/.local/share/komari` when unset), with the unit in `$HOME/.config/systemd/user`. Run the cleanup as the user who installed the Agent. For OpenRC, OpenWrt procd, Upstart, custom paths, macOS, or Docker, use the command generated by the dashboard.

### Windows

Open PowerShell as Administrator. The default service is `komari-agent` and the default directory is `$Env:ProgramFiles\Komari`:

```powershell
nssm stop komari-agent
nssm remove komari-agent confirm
Remove-Item -LiteralPath "$Env:ProgramFiles\Komari\komari-agent.exe", "$Env:ProgramFiles\Komari\nssm.exe", "$Env:ProgramFiles\Komari\auto-discovery.json" -Force -ErrorAction SilentlyContinue
Remove-Item -LiteralPath "$Env:ProgramFiles\Komari" -Force -ErrorAction SilentlyContinue
```

Replace the service name and directory if installation used custom values. The final command removes the directory only when it is empty.

### Docker

```bash
docker rm -f komari-agent
```

This keeps the image and volumes. For a Compose-managed container, run `docker compose down` from its project directory so Compose does not recreate it.
