# 私有站点：游客与管理资源隔离验收

本轮将 default、Retro 两个内置主题各自拆成管理员与游客两套独立编译产物。验收对象为当前源码构建的候选程序；生产脚本版、Docker 版仍保持 v1.2.14，未切换候选程序。

## 交付行为

- 游客入口只引用 `/share-assets/<theme>/` 的独立资源。构建时禁止引入账户、登录、管理页面及保存全局设置的模块，并扫描导出的 JS、CSS、HTML、JSON、TXT、SVG 和多语言文本。游客产物不包含应用登录按钮、登录流程、身份探测接口或管理路由，也不导出 source map。
- 私有模式下，`/private-assets/`、原 `/themes/<theme>/dist/`、根路径旧资源均由服务端检查管理员会话或安全入口凭证。只读分享凭证不能取得这些资源，即使已知文件名。根路径 manifest 只返回游客版本。
- 游客通过独立 `/viewer-api/` 只读通道访问。进入原后端处理器前剥离管理员会话、入口凭证、Authorization 和节点 token，防止管理员浏览器的分享标签页继承管理权限。HTTP、WebSocket 均受相同权限规则约束。
- 永久、临时分享 Cookie 均由服务端设置为 HttpOnly、SameSite=Lax；HTTPS 使用 Secure。到期和撤销继续由后端逐请求、逐 RPC 消息验证。匿名和伪造分享不能访问私有数据、游客静态产物或管理入口。
- 游客不执行站点 custom_head/custom_body、插件注入代码；返回带随机 nonce 的脚本 CSP、禁止嵌入、no-referrer 和不缓存响应。第三方主题游客侧回退为经过隔离构建的内置 default；管理员侧仍保留原主题能力。
- 关闭 CORS 或 WebSocket Origin 配置也不能绕过私有 Cookie 的跨站保护。原客户端缓存由退出服务的旧 worker 与游客启动脚本清理，不再预缓存管理端代码。
- 新生成的管理员入口采用 24 字节加密随机数；已有入口保留，避免升级后失去访问。若旧入口曾被公开，应由管理员在升级后轮换。

## 持续验证与边界

CI 同时构建四套资源、检查游客模块与导出内容、运行后端隔离测试和真实浏览器验收。手动 Release 工作流同样构建四套资源，并在下载产物前删除旧目录，避免将过期管理脚本混入发布包。

“游客拿不到登录代码”指启用私有模式后，本服务向没有管理员入口凭证的游客提供的资源。公开 GitHub 源码、第三方保存的旧文件、曾经下载过的内容无法追溯收回；浏览器缓存清理也不能删除用户自行保存的副本。安全入口本身是允许获取登录界面的凭证，应保密；取得登录界面仍不能代替管理员密码。分享链接是可转发的只读访问能力，泄露后应撤销或轮换。

本次有限用例通过不等于覆盖所有攻击或未知漏洞。未覆盖真实 Cloudflare 账户隧道、所有浏览器内核、无限流量 DDoS、外部 CDN 忽略源站缓存头的异常配置。生产发布后的域名、反向代理与实际分享访问仍需在用户手动构建新版本后单独验收。
