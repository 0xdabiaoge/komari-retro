# 远程工作台

工作台使用 React 与 xterm.js，沿用 Komari 的管理员会话和 Agent 通道。
界面参考独立终端的交互布局，自主实现；没有引入 Vue、Incus、KVM 服务或外部终端页面。

- 工具栏提供连接状态、重新连接、搜索、复制、清屏、常用命令、文件管理和设置。
- 深色、浅色、高对比度主题；字号、字体、光标、回滚行数和内边距保存后即时应用，不重建 Shell。
- 常用命令最多 50 条，仅由管理员访问，保存到现有工作台设置。点击“填入命令”不追加回车；多行内容需要先确认。不要在收藏中保存密码或令牌。
- 手机提供 Esc、Tab、Ctrl+C、Ctrl+D、方向键；支持软键盘引起的视口变化。
- 文件管理路径栏可填入切换目录命令，按操作系统路径格式引用，拒绝控制字符，不自动追加回车。
- 保留文件管理、编辑器、原有纯文本导出；没有新增分屏、ANSI 导出或 WebGL。

## 恢复与边界

浏览器网络断开后，服务端保留原 Agent 通道和 Shell，最多等待 5 分钟。
恢复 ID 绑定节点、管理员及创建时的登录凭据；换一个登录会话不能接管原终端。
客户端仅在 xterm 处理完输出后确认，服务端最多保留 256 KiB 未确认输出，发送窗口为 64 KiB。
慢浏览器通过 TCP 背压阻止积压无限增长，重连时重放未确认数据。

新 Agent 会声明会话恢复能力，区分 Shell 退出和通道断开。旧 Agent 仍可正常使用，浏览器重连不重建 Shell；但旧 Agent 自身终端通道断开时会结束该会话，要求手动新建，避免把 Shell 退出误判成网络问题并偷偷创建新 Shell。
Agent 通道中断的瞬间仍可能丢失部分尚未送达服务器的输出，界面会明确提示；服务端或 Agent 进程重启后的终端保活不在本次承诺范围内。
主动关闭、权限失效或退出登录会终止会话，不按网络故障保留。

## 验证

- `go test ./web/api/terminal ./web/connection ./web/rpc/jsonrpc`
- Agent 模块：`go test ./terminal`，包含原生系统 Shell 和重附着回归。
- Vite 启动后：`node komari-web/script/terminal.browser.mjs`，模拟通信验证界面、设置、收藏、粘贴、重连和移动布局。
- 真实隔离链路：`python script/terminal-real-fixture.py <服务端程序> <Agent程序>`。
  创建独立数据库及本地监听端口，验证真实 PTY、同一 Shell 环境恢复、即时设置及退出登录撤权；从不连接生产。
- 游客构建禁止引入整个 `pages/terminal` 模块，并继续执行私有站点浏览器验收。
