# 延迟探测预设

`catalog.json` 是服务端内置目录，只在管理员勾选并保存后创建任务，不会随升级自动启用。

- 中国大陆：31 个省级地区 × 电信/联通/移动 × IPv4/IPv6，共 186 项。使用 Zstatic 公开测试域名的 TCP 80 端口；IPv4 目录来自 https://lf3-ips.zstaticcdn.com/ ，IPv6 格式来自原作者说明 https://www.nodeseek.com/post-129987-1 。每项保留来源链接。
- Google/Cloudflare：官方公共 DNS 地址，使用 ICMP，分别提供 IPv4、IPv6。Anycast 不代表固定地理位置。
- 海外：11 个地区的服务商公开测试端点，共 20 项；每项保留服务商来源。堪萨斯城端点实际位于密苏里州，名称已注明；安克雷奇端点位于阿拉斯加。二者暂未收录可靠的公开 IPv6 目标。

维护目录时须核对服务商公布的位置、地址和端口，不能仅凭域名猜测地理位置或 IPv6 地址。DNS 有记录不等于从每个节点都能连通。IPv6 探测要求节点具有 IPv6 网络，ICMP 还受本机权限、防火墙和目标限速影响。

导入按类型和目标合并，保留原任务 ID、名称、间隔和历史；仅合并服务器关联及默认启用设置。一次选择使用一个数据库事务，失败全部回滚。预设入口仅管理员可用，游客任务列表及历史摘要会过滤隐藏节点关联。

不要无条件开启全部目标：186 个目标按 60 秒间隔，每台节点每天约产生 267,840 条探测记录。界面按本次选择显示记录量估算。

目录或导入逻辑修改后，运行 `go test ./pkg/pingpresets ./database/tasks ./web/rpc/jsonrpc`；前端修改还需运行 `komari-web` 的 `npm test`，并通过 `script/private-audience-fixture.py` 完成隔离浏览器验收。
